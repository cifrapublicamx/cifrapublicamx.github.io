Para qué sirve, y para qué no

Sirve para ver hacia dónde se está moviendo el comercio de León, y para saber dónde buscar.

No sirve para escoger un local: el directorio del INEGI no cuenta lo informal ni cuánto vende cada negocio. Para eso hay que ir a ver la calle.

Qué tumbaría esta lectura: que la siguiente foto completa del INEGI muestre que las orillas dejaron de crecer, o que las zonas nuevas resulten ser solo zonas que el INEGI empezó a contar.
